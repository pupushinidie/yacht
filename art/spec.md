## 1. 风格

| 项 | 规定 |
|---|---|
| 基调 | 月夜里的柚木游艇甲板：藏青夜海、星星、柚木桌面、黄铜马灯的暖光。夜间版是默认；白天版是碧海白帆、浅柚木、阳光 |
| 光照 | 所有小图（骰子、图标、头像、骰盅）统一**左上方来光**：左上 1px 亮边，右下暗边，骰子底部露 3–4px 侧面（厚度）。夜间场景的主光是左边马灯的暖黄 + 海面冷月光；白天是正午顶光 |
| 描边 | 小图一圈 1px 深色描边 `#1e1820`（不用纯黑）；骰子描边同色。场景不描边 |
| 像素密度 | 场景 512×288（highly detailed，大色块）；骰子 32×32 原图、桌面 3× / 手机 2×；计分表图标 24×24 原图、1×；头像 32×32、桌面 2× / 手机 1× |
| 文字 | **所有图里一个字、一个数字都不要**；场景里的招牌、纸张也不要字样。界面里不出现「Yahtzee」 |
| 不要 | 像国旗的旗帜、海盗骷髅旗（会像别的游戏）、像名人或知名角色（迪士尼小美人鱼、海绵宝宝里的蟹老板、企鹅家族）、人物 |

## 2. 素材清单

「来源」：**PixelLab** = 出候选、自查后挑定；**代码** = `art/dice.py` / `art/fx.py` 画（需要准确排布的骰点、图标、特效），**代码+PixelLab** = 代码合成 PixelLab 的图。
「夜/日」：**同** = 一张图两种主题都用；**分** = 夜间、白天各一张。

## 3. 界面怎么用（给开发 agent）

- 估算尺寸（1440×790）：掷骰区 5 颗骰子 3× = 108px，间距 16 → 约 620×150；计分表 16 行（13 格 + 上半区小计、奖励、总分）× 行高 36 ≈ 580，图标 24 1× 放行首。390×664 手机：骰子 2×（72）× 5 + 间距 = 380，计分表行高 26、图标 24。1920×960 可以把图标放 2×。
- 「留下」状态两种画法都给：骰子图本身（`-held` 版带黄铜框、上移 2px），界面不用再画框。
- 预览分数（灰字）、格名、数字、+35、总分都由界面写字，不进图。
- 需要的代码绘制部分（骰点、图标）出自 `art/dice.py`，改样式重跑即可，文件名不变。
